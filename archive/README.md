# Archive

This directory contains historical or non-active repository material moved out of the live Applicating operational contour.

## Purpose
The archive preserves context without allowing legacy files to keep defining:
- active CI/CD workflows
- active deployment charts or sealed secrets
- current runtime documentation
- current product vocabulary

## Current archive bucket
- `archive/repo-drift/` — material removed from the active contour during cleanup waves

## Recent archived examples
- legacy product-era CLI entrypoints
- obsolete contract harness files
- retired workflow, deployment and tooling residue

- `archive/repo-drift/admin-ui-archive/` stores archived experimental UI shells removed from the live delivery contour.
- `archive/repo-drift/legacy-tree-archive/` stores the old top-level legacy tree removed from the live root.
