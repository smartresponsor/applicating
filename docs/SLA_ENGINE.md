# SLA Engine (v22.2)
*обновлено 2025-10-09*

## Что делает
- Рассчитывает факт доступности vs контрактный минимум, рекомендует SLA-тир.
- Вычисляет компенсацию (credits) при нарушении.
- Симулирует стоимость SLO по латентности, ошибкам и нагрузке.

## CLI пример
```bash
bin/sla-run tenantA 99.4 99.5 12 120 standard 450 0.018 800
```

## SQL
- `sla_contracts` — договорные параметры (минимальный SLA).
- `sla_events` — события расчёта SLA/кредитов.
- `slo_cost_snapshots` — снимки стоимости SLO по метрикам.
